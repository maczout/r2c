# 2026-11-19-02: a results dashboard for the owner's review

Who: the developer (a coding agent), with the owner.
Branch at the end: `dashboard`.

## Goal

The owner's review time is a bottleneck. Asked for a tool that shows at a glance how much of
r2c is tested against r2x and how close the results are.

## Done

- `tools/dashboard.py`: one self-contained HTML page from a verify run (or the committed
  `docs/verification-results.json`): coverage grid (section × loading path) with the "Not
  compared" list from `docs/verification.md`; peak and curve differences per case; a heatmap
  of detail-view differences at the peak; control curves of Response and r2c overlaid.
  Tolerances from `docs/acceptance.md` are drawn only where set. Output is git-ignored.
- `tests/test_dashboard.py` (smoke test). Pointers in `CLAUDE.md`, `README.md` and
  `docs/status.md`.
- `tools/report.py` now keeps r2c's curve on each case's compared chart in the results JSON
  (`sub_curve`), so the page can be built from committed files alone. `tools/check.py` warns
  while they are missing; the committed JSON predates this (see `docs/status.md`, section 6).
- `.github/workflows/pages.yml`: on every push to `main`, CI builds the page from the
  committed results and publishes it with GitHub Pages (https://maczout.github.io/r2c/). The
  page says when the results are stale against the kernel at HEAD.

## Tried and dropped

Nothing.

## Decisions

- Developer: the page shows differences and assesses nothing until acceptance.md sets
  tolerances, as report.py does.
- Developer: detail-view cells are hatched where r2c's compared stage is more than 5 % from
  Response's peak in control value, to show the two are different states. The 5 % is a
  display threshold, not a tolerance; reading, for the owner to confirm.
- Owner (2026-11-19): a public results page is fine for now (the work is not being shared
  actively yet); it should stay current as a matter of course.
- Developer: the page is a view of the committed results, built by CI, not a committed file,
  so the results stay in one place and updating the results updates the page.
- Developer: the page carries a short not-affiliated / does-not-check-designs line, as r2x's
  records do, since it is public.

## Open questions for the owner

None new. Settings > Pages > Source must be set to "GitHub Actions" once, by the owner.

## Evidence

- Measured, cloud session (2 cores): `python tools/verify.py tests/oracle --out OUT --jobs 2`
  without Response's sample inputs ran the 18 Newbeam cases; peak and curve figures equal the
  committed run's (ae65cf9) for all 18. The 7 sample-input cases were skipped (input not
  found), so the preview page has Response's curve alone for those.
- `python tools/dashboard.py --curves OUT` then rendered in Chrome at 1100 px (light) and
