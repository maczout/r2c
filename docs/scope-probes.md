# Scope probes: what Response-2000 does with each input

Generated by `python tools/probe.py OUT_DIR --table docs/scope-probes.md` from the probe's results; do not edit. Each row is one input of `tools/variants.py` put through r2x's worker: Response's own Save As of it, and a solve at the loads shown, compared with the same solve of the variant's base. What the rows mean for r2c's scope is in `docs/scope.md`.

- **Save As**: how many elements of the section differ between the input and Response's own save of it (0: Response read every attribute as given; the order of the elements is not compared).
- **Peak / base**: the largest load on the bottom control chart over the base's.
- **Charts**: how many charts (control charts and the detail views at the peak) differ from the base's by a byte. `0 of n`: the feature does not reach the analysis at this loading. Where the stage count or the peak stage differs, every chart at the peak counts as different.
- **r2c**: whether r2c reads the input and sets up its analysis (nothing is solved here).
- A probe whose input is used as it is (a file in other units, Newbeam under other loads) has no base to compare with: those two columns are empty.
